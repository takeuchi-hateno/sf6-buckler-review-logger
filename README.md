# SF6 Buckler Review Logger

Street Fighter 6 の Buckler `BATTLE LOG` を貼り付けて、MR推移と対戦振り返りをローカル保存する単一HTMLツールです。

## 主な機能

- 対戦直後に「一番困ったこと」を1タップ記録
- 後からBucklerログを貼ると、時刻が近い試合へ対戦直後メモを自動紐付け
- 同じ対戦相手との連戦を1グループで表示
- 各試合は必要なときだけ詳細編集
- 対空失敗の内訳、起き上がり防御、取り返し行動を任意で補足
- 相手キャラをBucklerから判定し、キャラ固有の困りごと候補を表示
- MR推移・勝率・相手キャラ別戦績を集計
- ChatGPTへ渡す振り返りプロンプトを生成
- localStorage保存 + JSONバックアップ/復元

## 使い方

1. ランクマ中は `対戦直後メモ` タブを開いておく。
2. 1試合終わるたび、一番困った項目を1つだけタップする。
3. セッション後にBucklerのBATTLE LOGページを丸ごとコピーする。
4. `ログ取込` に貼り付けて `解析して保存`。
5. `試合レビュー` で自動紐付け結果を確認・必要なら補足する。
6. `ChatGPT用コピー` から分析用テキストを生成する。

## データ保存

データはブラウザの `localStorage` に保存されます。サーバーへの自動送信はありません。
ブラウザや端末を変える場合は `設定・バックアップ` からJSONを書き出してください。

## GitHub Pages

`index.html` をリポジトリ直下に置き、GitHub Pagesを `main / root` から公開すればそのまま利用できます。
